# ระบบรายงานผลหมาย (ผนวกรวม summon-report เข้ากับ SLTS) — v2.5.0

ใช้งานบน **PC และแท็บเล็ตที่เปิดโหมด PC** (มือถือคงหน้าจอเดิมสำหรับงานภาคสนาม)

## 1. ขั้นตอนใช้งานประจำรอบ (เมนู **รายงานหมาย** — ทีละขั้นตอน)

มือถือถ่ายภาพ/อัปโหลดภาพส่งหมายตามปกติ แล้วบน PC เปิดเมนู **รายงานหมาย**

| ขั้น | ทำอะไร |
|---|---|
| ① โซนและช่วงเวลา | ระบบแสดง **โซนจ่ายหมายปัจจุบัน** และ **ช่วงรายงาน** = วันจันทร์ของสัปดาห์ก่อน → วันศุกร์ของสัปดาห์ที่ใช้งาน (เลื่อนดูสัปดาห์ก่อนได้) ครั้งแรกให้เลือกโซนและวันที่เริ่มโซน |
| ② ภาพส่งหมายในโซน | ภาพที่ถ่ายจากแอป/อัปโหลดเอง (มือถือ แท็บเล็ต PC) ในโซนและช่วงเวลา — **ไม่มีภาพ → ปุ่ม "ไปหน้าอัปโหลดภาพส่งหมาย"** |
| ③ ตรวจกับบัญชีจ่ายหมาย | นำเข้า `litigant_rpt_issued_sendbyofficer.xls` (**ทุกครั้ง**; เลือก `litigant_rpt_accexpense.xls` มาพร้อมกันได้) → สรุป หมายในบัญชี / มีภาพแล้ว / **ยังไม่มีภาพ** / **ภาพที่ไม่พบในบัญชี** |
| ④ สร้างแบบรายงานหมาย | กด **รายงานหมาย** ทีละรายการ (ภาพแนบให้อัตโนมัติ) → Word ตามแบบศาล · ดาวน์โหลด Word ที่รายงานแล้วทั้งหมด (.zip) · ทางลัดไปบันทึกข้อความขออนุมัติเบิก |

**โซนจ่ายหมาย** = อำเภอ (อ.เมืองอุดรธานีแบ่งตามตำบล) — แต่ละผู้ใช้มีโซนของตัวเอง เลื่อนไปโซนถัดไปอัตโนมัติทุก 2 สัปดาห์
กด **เลื่อนไปโซนถัดไป / โซนก่อนหน้า** เองได้ (เริ่มนับ 2 สัปดาห์ใหม่ตั้งแต่วันจันทร์นี้) · ผู้ดูแลระบบจัดลำดับ เปิด/ปิด และรวมพื้นที่เป็นโซนเดียวกันได้ที่
**ข้อมูลรายงานผลหมาย → ผู้ลงนาม / โซนจ่ายหมาย** (ค่าเริ่มต้นรวม อ.ประจักษ์ศิลปาคม กับ อ.กุมภวาปี)

เลขคดีหมาย ต.: ช่อง "เลขดำที่" ที่มีเลขขึ้นต้นด้วย **ต** = หมายต่างจังหวัด ใช้เลข ต. เป็นเลขหลัก · เทียบเลขคดีถึงปี พ.ศ. หลัง "/" เท่านั้น

สิ้นรอบ: **ข้อมูลรายงานผลหมาย → บันทึกข้อความ / ใบสำคัญรับเงิน** → รายงานหมายฟรี (ดึงหมายฟรีที่ "เบิก" อัตโนมัติ) / หมายเงิน
หน้า "รายการเส้นทางส่งหมายจากมือถือ" แบบเดิม เปิดได้จากลิงก์ท้ายหน้ารายงานหมาย

## 2. แบบรายงาน Word (4 แบบ เลือกอัตโนมัติ)

| ประเภทหมาย | ผลการส่งหมาย "003 ส่งได้โดยวิธีปิดประกาศ" | ผลอื่นๆ |
|---|---|---|
| หมายศาล (เลขคดีของศาลนี้) | `local_notice` (บันทึกการปิดประกาศ) | `local_normal` (บันทึกการปิดหมาย/คำบังคับ) |
| หมายต่างจังหวัด (เลข ต.) | `t_notice` (หน้า 1 แบบ ต. + หน้า 2 บันทึกการปิดประกาศ) | `t_normal` |

เงินในแบบรายงาน

| | ค่าบริการส่งครั้งนี้ / ตัวหนังสือ | โดยตัดจ่ายจากเงินของ |
|---|---|---|
| หมายเงิน (ราคา > 0 ในบัญชีจ่ายหมาย) | ราคาตามบัญชีจ่ายหมาย | ใบเสร็จ (จากไฟล์ accexpense หรือกรอกเอง) · หมาย ต. ใบสำคัญรับเงินใช้ "ศาลผู้วางเงิน" |
| หมายฟรี — **เบิก** | อัตราหมายฟรีตามตำบล (แก้ได้) | **เงินงบประมาณ** |
| หมายฟรี — **ไม่เบิก** | เว้นว่าง | เว้นว่าง |

ข้อมูลจากบัญชีจ่ายหมายที่ใช้ในแบบ: เลข ต., คดีหมายเลขดำ/แดง, โจทก์, จำเลย, หมายอะไร, หมายถึงใคร, ที่อยู่ (บ้านเลขที่/หมู่/ซอย/ถนน), ตำบล, อำเภอ, ราคา, ผู้ส่งหมาย, ผู้วางเงิน, ผลการส่งหมาย
ข้อมูลที่กรอกเพิ่ม: วันที่จ่าย/ส่งหมาย, ผลการส่งหมาย (รหัส 001–019), ประเภทการส่งหมาย, ผู้ตรวจ+ตำแหน่ง, ผู้จ่ายเงิน+ตำแหน่ง, วันที่รับเงิน, วันที่บันทึกผลหมาย, ศาลต้นทาง/หนังสือนำส่ง (หมาย ต.), บันทึกการปิดหมาย

- ตัวเลขในเอกสารเป็น **เลขไทย** ตามแบบฟอร์มศาล (เปลี่ยนเป็นอารบิกได้ที่ ผู้ลงนามและตั้งค่า)
- ผู้ตรวจ / ผู้จ่ายเงิน: เจ้าหน้าที่ทุกคนเพิ่มได้ (ปุ่ม + ในแบบฟอร์ม) ค่าเริ่มต้นของทุกคนตั้งได้เฉพาะแอดมิน

## 3. ฟังก์ชันที่ผนวกจาก summon-report

| summon-report | ใน SLTS |
|---|---|
| ตารางอัตราหมายเงิน/หมายฟรี, แก้ไข, นำเข้า Excel/PDF, ส่งออก Excel/PDF, หัวประกาศ/หมายเหตุ | แท็บ อัตราค่านำหมาย |
| บันทึกข้อความขออนุมัติเบิก (Word จากแม่แบบเดิม + PDF) | แท็บ บันทึกข้อความ / ใบสำคัญรับเงิน |
| ใบสำคัญรับเงินหมายฟรี (Excel + PDF) คำนวณ 100% / 50% / ห้ามเบิกซ้ำบ้าน | แท็บ บันทึกข้อความ / ใบสำคัญรับเงิน |
| คำสั่งศาลแบบ snapshot, รายชื่อผู้อำนวยการ/รักษาราชการแทน | แท็บ ผู้ลงนามและตั้งค่า |
| ผู้ใช้/สิทธิ์ | ใช้ผู้ใช้และสิทธิ์ของ SLTS (admin / local_advisor / user) |
| แดชบอร์ด | สรุปตัวเลขด้านบนแท็บ รายงานผลหมาย |

## 4. โครงสร้างไฟล์

```
api/report.js            API ระบบรายงาน (POST /api/report, token เดียวกับ /api/slts)
lib/report-schema.js     ตาราง sr_* (สร้างอัตโนมัติครั้งแรก) + ค่าเริ่มต้น
lib/report-rates-seed.json  อัตราตั้งต้น 157 ตำบล (หมายเงิน/หมายฟรี)
js/report-logic.js       อ่าน Excel, วันที่/เลขไทย, บาทเป็นตัวหนังสือ, อัตรา, เลือกแม่แบบ, เตรียมข้อมูล Word
js/report-docx.js        เติมแม่แบบ Word + แนบภาพ (JSZip)
js/report-xlsx.js        เขียน Excel แบบมีรูปแบบ (แทน ExcelJS)
js/report-exports.js     ใบสำคัญรับเงิน, อัตรา, บันทึกข้อความ (Excel/Word/หน้าพิมพ์ PDF)
js/slts-report.js        หน้าจอทั้งหมด + ผนวกกับแท็บเดิม
css/official.css         ธีมทางการ (โหมด PC) + ส่วนประกอบ sr-*
templates/report/*.docx  แม่แบบ Word (สร้างจากไฟล์ตัวอย่างของศาล ด้วย tools/build-report-templates.py)
fonts/                   TH SarabunPSK / TH SarabunIT๙ สำหรับหน้าพิมพ์ PDF
tests/report.test.js     ทดสอบตรรกะ + แม่แบบ (node --test tests/report.test.js)
```

ตารางฐานข้อมูล: `sr_settings, sr_rates, sr_court_orders, sr_signers, sr_batches, sr_issued, sr_memos, sr_memo_items`
(เพิ่มอย่างเดียว ไม่แก้ตารางเดิมของ SLTS)

## 5. หมายเหตุ

- ไฟล์ Excel อ่านในเบราว์เซอร์ด้วย SheetJS (โหลดจาก cdn.sheetjs.com เมื่อกดนำเข้าครั้งแรก)
- ภาพจาก Google Drive: ถ้าเบราว์เซอร์ดึงตรงไม่ได้ ระบบดึงผ่านเซิร์ฟเวอร์ (`sr_photo`) — เข้าถึงได้เฉพาะภาพของตนเอง/แอดมิน
- แม่แบบ Word สร้างจากไฟล์ .doc ของศาลที่แปลงเป็น .docx — ตรวจทานการแสดงผลใน Microsoft Word ครั้งแรกที่ใช้งาน
